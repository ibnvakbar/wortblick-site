# Wortblick website

The website for [Wortblick](https://ibnvakbar.github.io/wortblick-site/), a browser extension for reading German: what it does, support contact and the privacy policy. Plain HTML and CSS, served by GitHub Pages from the `main` branch.

The font is Archivo (SIL Open Font License, see `fonts/OFL.txt`). Dictionary data credited on the site comes from Wiktionary (CC BY-SA 4.0).
